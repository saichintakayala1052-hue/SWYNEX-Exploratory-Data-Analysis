# Titanic Dataset — Exploratory Data Analysis

An end-to-end EDA portfolio project using Python and Jupyter Notebook on a cleaned Titanic passenger dataset.

## Objective
Explore the data, calculate important statistics, identify trends/patterns, detect anomalies/outliers, create visualizations, and communicate useful insights.

## Dataset
**891 records, 12 columns.** The cleaned dataset is stored in `data/titanic_cleaned.csv`.

## Key Findings
- Overall survival rate is approximately **38.38%**.
- Female passengers had a substantially higher survival rate than male passengers.
- First-class passengers had a considerably higher survival rate than third-class passengers.
- Children showed relatively high survival.
- Small family groups generally performed better than very large families.
- Fare was right-skewed and contained high-value outliers.
- The cleaned dataset has no missing values or duplicate records.
